# HPLC Tool


This repository contains the **empty version** of the HPLC Tool. It is intended for a new method-development session, with specifications and experimental data entered by the user.

## How to Use

1. Open the HPLC Tool.
2. Enter the method specifications.
3. Upload the chromatogram data file(s).
4. Review the imported run information.
5. Follow the decision and next-run conditions generated by the tool.
6. Continue uploading runs sequentially as method development progresses.

## Decision Workflow

The tool evaluates each run in the following order:

**Back Pressure → Peak Count → Retention Time → Resolution**

Depending on the results, the tool guides the user through the appropriate next step in the Retention and Selectivity workflow.

## Input Data

The tool can extract relevant information from uploaded chromatographic data, including:

- Peak count
- Retention time of the last peak
- Worst adjacent resolution
- Back pressure
- Experimental conditions where available

Missing or conflicting information can be reviewed within the tool.

## Empty Version

This version intentionally contains **no pre-loaded experimental session or method specifications**.
A separate worked version/exported record contains the experimental development series.

## Scope

The HPLC Tool implements **Flow Chart 1 — Retention (k) + Selectivity (α)**.
Efficiency (N) and gradient optimisation are outside the implemented scope. Where appropriate, the tool directs the user to proceed to Efficiency rather than performing those calculations.

## Running the Tool
The HPLC Tool runs directly in the browser and requires no installation.
When hosted using GitHub Pages, simply open the published site to begin.
