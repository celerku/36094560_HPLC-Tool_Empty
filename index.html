Advanced operating limits and peak review · optional

CSV/XLSX imports automatically switch off peaks below 10,000 height counts; exactly 10,000 stays included. Leaving the warning threshold blank adds no custom warning. Entering a threshold only flags included peaks on Results so you can review their Keep switches; 0 disables these warnings. It never changes peak inclusion.

Flow bounds are optional planning settings, not verified instrument ratings. Blank uses 0.1–5 mL/min. Use limits appropriate to the actual instrument and column.

Calculation assumptions

G2 stops at the minimum flow or if the next measured Rs improves by no more than 0.01. Geometry uses porosity 0.68 unless measured Vm is entered. Pressure and resolution predictions use the course screening models. Timing assumptions are shown with each run.
